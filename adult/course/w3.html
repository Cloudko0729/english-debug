📅 W3 — 索取型號序號與錯誤訊息

← 課程目錄 · 本週產出：客戶描述不清楚時，一段信／一通電話就能問到你需要的資訊

🎯 本週結束時你要能：①客戶來信資訊不足時，禮貌地一次問齊型號、序號、錯誤訊息、發生時機 ②收到資訊後能清楚說明下一步

⭐ 本週 5 個核心句

1. Thank you for your inquiry — to help us get started, could you provide a few more details?
謝謝你的詢問——為了能開始處理，可以請你提供多一點細節嗎？（開場過渡句）
先謝再問，比直接列問題清單更有禮貌
2. Could you please provide the model number and serial number of the unit?
可以請你提供設備的型號與序號嗎？（索取型號序號）
model number／serial number 通常一起問，兩者缺一都查不到保固或料件紀錄
3. Could you also send us a screenshot of the error message you are seeing?
可以請你也傳一張錯誤訊息的截圖給我們嗎？（索取錯誤截圖）
screenshot＋of，別用 about；screenshot 比 photo 更準確（軟體訊息用 screenshot，硬體外觀用 photo）
4. It would help if you could tell us when the issue occurs, and once we have this information, we can start the diagnosis right away.
如果你能告訴我們問題發生的時機會很有幫助，等我們拿到這些資訊後就能馬上開始診斷。（詢問時機＋承諾下一步）
「during power-up or under load」是最常見的兩種故障情境分類，可以直接套用在任何症狀詢問句
5. Please let us know if you need any help finding this information.
如果你需要協助找這些資訊，請告訴我們。（提供協助／邀請回應）
need help＋finding（動名詞），不是 need help find

📧 Email 骨架（索取資訊版）

① Subject：RE: Repair Inquiry — Additional Information Needed
② 稱呼：Dear Mr. Lin,
③ 開場過渡：Thank you for your inquiry — to help us get started, could you provide a few more details?
④ 正事（一次問齊）：型號序號 → 錯誤截圖 → 發生時機
⑤ 結尾：Please let us know if you need any help finding this information. ＋ Best regards, Cloud

🎤 電話索取資訊講稿（口說版）

Hi, this is Cloud from Fix-well Technology. Thank you for your inquiry — to help us get started, could you provide a few more details? Could you tell me the model number and serial number of the unit, and send us a screenshot of the error message? It would also help to know when the issue occurs — during power-up or under load. Once we have this information, we can start the diagnosis right away.

練法：先聽一次 → 跟讀 3 次 → 不看稿自己講一次並錄音。

📧 Email 常見錯誤語法

Please send me a picture about the error message.
picture 後面接介係詞要用 of，不是 about
Could you please send us a picture of the error message?
What is your model number and serial number?
直接問句在客服信件裡顯得生硬，用 Could you please provide 更委婉、更專業
Could you please provide the model number and serial number?
Please tell me when happen this problem.
子句要用直述句語序（主詞＋動詞），不能用疑問句語序：when this problem happens
Could you tell us when this problem happens?
If we will receive this information, we can start diagnosis.
if 子句不能用 will，要用現在式；診斷前也別漏冠詞 the diagnosis
Once we receive this information, we can start the diagnosis right away.
Please let us know if you need help find this information.
need help 後面接動詞要用 -ing：need help finding，不能用原形 find
Please let us know if you need any help finding this information.

🛠️ 維修紀錄撰寫範例

英文維修紀錄固定寫三層：Symptom（現象）→ Action（處置）→ Result（結果），每層一句就好。標準版之後附「精簡版」——真實工程師交班常用的電報式簡寫，不用完整文法，但夠清楚。

Symptom：The fuse was blown when the unit was powered up.
Action：Replaced the fuse and checked the power net for a short before retesting.
Result：The unit powered up normally with no further abnormality.
精簡版：Fuse blown @ power-up → replaced fuse, checked net for short → powers up fine now.
Symptom：The ADC output drifted during the offset check.
Action：Recalibrated the ADC and repeated the offset check.
Result：The offset check passed within the allowed tolerance.
精簡版：ADC drift @ offset check → recal'd ADC, re-checked → pass, within tolerance.
Symptom：The sensor reported an incorrect value during startup.
Action：Replaced the sensor and reran the startup sequence.
Result：The sensor reading was correct and the unit passed verification.
精簡版：Sensor value wrong @ startup → replaced sensor, reran seq → reading OK, passed verification.

📖 W3 週一 — 讀信＋圈句型

← 本週重點 · 讀一封索取資訊的回覆信，找出可重複使用的句型

先讀這封信（改編自真實維修回覆信，已去識別化）

Subject: RE: Repair Inquiry — Additional Information Needed
Dear Mr. Lin,

Thank you for your inquiry — to help us get started, could you provide a few more details?

Could you please provide the model number and serial number of the unit? Could you also send us a screenshot of the error message you are seeing? It would help if you could tell us when the issue occurs, and once we have this information, we can start the diagnosis right away.

Please let us know if you need any help finding this information.

Best regards,
Cloud

粗體就是本週 5 個核心句——它們在幾乎每封「索取資訊」的信都能重複使用。讀兩次再作答。

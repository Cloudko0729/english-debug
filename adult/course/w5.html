📅 W5 — 維修報價

← 課程目錄 · 本週產出：檢查完成後，一封信報出費用與範圍，讓客戶能直接決定修或不修

🎯 本週結束時你要能：①依檢查結果報出維修費用與涵蓋範圍 ②說明報價有效期，並要求書面確認才動工 ③客戶不修時能提出原樣寄回

⭐ 本週 5 個核心句

1. Based on the inspection, we have prepared a quotation for the repair.
根據檢查結果，我們已備妥維修報價（開場：報價的依據）
Based on the inspection 先交代報價是怎麼來的，客戶才不會覺得數字是憑空喊的
2. The total repair cost is USD 480, including parts and labor.
維修總費用為 480 美元，含料件與工時（金額＋涵蓋範圍）
including parts and labor 一定要寫出來，這是客戶最常追問的第一個問題
3. The quotation is valid for 30 days from the date of this email.
本報價自本信日期起 30 天內有效（有效期）
valid for＋期間＋from the date of，是報價信的固定寫法，避免半年後客戶拿舊報價來談
4. Please confirm in writing before we proceed with the repair.
請以書面確認後我們才會開始維修（先確認才動工）
in writing 是關鍵字，口頭同意事後說不清；沿用 W4 學過的 before we proceed
5. If you prefer not to proceed, we can return the unit as it is.
若您不打算維修，我們可以將設備原樣寄回（給對方退路）
as it is＝維持現狀不動工。給對方台階，比只丟一個價格更容易收到回覆

📧 Email 骨架（維修報價）

① Subject：Repair Quotation — Model TX-200, S/N 45120933
② 稱呼：Dear Mr. Yeh,
③ 開場：Based on the inspection, we have prepared a quotation for the repair.
④ 正事：費用與涵蓋範圍 → 報價有效期 → 需書面確認才動工 → 不修的話可原樣寄回
⑤ 結尾：Please let us know how you would like to proceed. ＋ Best regards, Cloud

🎤 電話進度告知講稿（口說版）

Hi, this is Cloud from Fix-well Technology. We've finished the inspection, and I'm calling about the quotation. The total repair cost is four hundred and eighty US dollars, including parts and labor. The quotation is valid for thirty days. We'll need your confirmation in writing before we start the repair — and if you'd rather not proceed, we can return the unit as it is.

練法：先聽一次 → 跟讀 3 次 → 不看稿自己講一次並錄音。

📧 Email 常見錯誤語法

We already prepare a quotation for you.
報價已經備妥是已完成的動作，要用現在完成式 have prepared；already 放在 have 之後
Based on the inspection, we have prepared a quotation for the repair.
The cost is include parts and labor.
is 和 include 兩個動詞不能並排。用 including 當補充說明，或改成 The cost includes…
The total repair cost is USD 480, including parts and labor.
This quotation valid 30 days.
valid 是形容詞，前面要有 be 動詞；期間要用 for，並說明從哪天起算
The quotation is valid for 30 days from the date of this email.
Please confirm us before we start repair.
confirm 後面直接接你要確認的事，不是接人；start repair 少了限定詞，改用 proceed with the repair 更專業
Please confirm in writing before we proceed with the repair.
If you don't want repair, we can send back the unit for you.
don't want repair 太口語且少了 to；send back 在正式信裡用 return 較合適
If you prefer not to proceed, we can return the unit as it is.

🛠️ 維修紀錄撰寫範例

英文維修紀錄固定寫三層：Symptom（現象）→ Action（處置）→ Result（結果），每層一句就好。標準版之後附「精簡版」——真實工程師交班常用的電報式簡寫，不用完整文法，但夠清楚。

Symptom：The power module was found damaged during the electrical inspection.
Action：Quoted the replacement cost and held the unit for customer approval.
Result：The customer approved the quotation and the repair was scheduled.
精簡版：Power module damaged @ electrical inspection → quoted replacement, held for approval → approved, repair scheduled.
Symptom：Two capacitors measured out of specification during the functional test.
Action：Listed both parts in the quotation together with the estimated labor time.
Result：The quotation was sent and acknowledged by the customer the same day.
精簡版：2 caps out of spec @ functional test → listed in quote w/ labor est. → quote sent, acknowledged same day.
Symptom：The board damage was beyond economical repair.
Action：Informed the customer and offered to return the unit as it is.
Result：The customer chose to have the unit returned without repair.
精簡版：Damage beyond economical repair → informed customer, offered return as-is → returned, no repair.

# 成人英語重建 — Claude 大綱草案 v1（2026-07-10）

## 使用者輪廓（從 223 封真實工作信分析）
- 半導體測試設備維修公司（Fix-well）工程/業務窗口
- 高頻場景：維修報價與交期、維修狀態回報、RMA 退修、料件詢價、異常說明、客戶催件、原廠/客戶三方轉達
- 目標程度：簡單 → 中階，「可勉強溝通」= CEFR A2 → B1-
- 每日可投入：10 分鐘；週末可稍多

## 六個月弧線（26 週，每週一場景，三線共用同一場景）
| 月 | 主題弧 | 週場景舉例 |
|----|--------|-----------|
| M1 打底 | 句子骨架＋開場結尾 | 自我介紹與公司一句話 / email 骨架（主旨/開頭/結尾）/ 電話接聽開場 / 聽不懂求生句 |
| M2 維修核心 | 最高頻業務 | 維修狀態回報 / 報價與交期 / 收到詢價的回覆 / 出貨與追蹤 |

| M6 整合 | 全流程模擬 | 詢價→報價→修→驗→出貨 完整案件（信）/ 同案件的電話版 / 來訪簡報版 / 總複習 |

## 每日 10 分鐘（週節奏）
- 週一 場景句型 3 句（真實信抽出、debug 式：原句→問題→自然版）
- 週二 郵件改寫 1 題（給中式英文/中文，寫成自然英文，附範答）
- 週三 Shadowing（該週口說句 5 句，ElevenLabs 語音跟讀）
- 週四 對話反應（聽問句→限時選/說回應）
- 週五 輸出日（寫 3 句本週場景的自己版本）＋錯誤複習
- 週六日 選做：補做或聽整週語音

## 素材管線
1. mail 語料 → 每週場景抽 5~10 句真實句（去識別化：客戶名/料號改假名）
2. Debug 分析進 mistakes/（bug list 累積）
3. 好句進 sentence_bank/（依場景分檔）
4. 口說講稿 → ElevenLabs 生成（家長現有流程）
5. 練習頁 = 網頁（同 kids 引擎風格：自動批改、進度記錄）

## 評量
- 每月一次「整合測驗」：一封信全寫＋一段口說自錄
- 錯誤追蹤：答錯句型自動進複習池（間隔重複）

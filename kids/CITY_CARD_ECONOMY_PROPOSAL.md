# 兒童英語遊戲小島：世界城市卡與金幣回收機制方案

> 狀態：設計提案，尚未實作  
> 主要影響檔案：`kids/island.html`  
> 審閱重點：學習節奏、兒童挫折感、金幣通膨、舊存檔相容性、實作複雜度

## 1. 背景

目前遊戲小島的主要循環是：

1. 完成英文練習取得金幣。
2. 使用金幣建造島嶼建築。
3. 建築隨放置天數自動升級。
4. 部分建築每天持續生產金幣。
5. 玩家再用收入建造更多建築。

現有「今日訪客」則是：

1. 每天出現一位訪客。
2. 玩家完成 3 題英文聽力選擇題。
3. 答對至少 2 題後，解鎖一個特價訪客商品。
4. 訪客商品目前為熱氣球、石像、花鐘，售價約 180～200 金幣。

## 2. 目前問題

### 2.1 金幣會在中後期快速增加

- 英文練習、島民委託板、打字遊戲與島嶼建築都會產生金幣。
- 生產型建築會長期產幣，並隨時間自動升級。
- 玩家島嶼發展後，每日被動收入會持續上升。

### 2.2 永久金幣消耗不足

- 建築數量與特殊商品有限。
- 現行拆除機制為全額退款，建造成本不一定形成永久回收。
- 三種訪客商品都是唯一建築，全部取得後，今日訪客不再具有長期消費價值。

### 2.3 今日訪客缺少長期收藏目標

- 訪客人物與商品會輪替，但缺少清楚的收藏進度。
- 每天的聽力題與前一天沒有故事上的連續性。
- 完成後主要目標仍是購買單一商品，難以支撐數月以上的使用。

## 3. 設計目標

1. 將今日訪客改成具有長期進度的世界城市收藏。
2. 每天仍保留短時間、低壓力的英文學習活動。
3. 不用「沒登入就扣錢」或「連續登入中斷歸零」懲罰兒童。
4. 城市卡是學習獎勵，不應被金幣不足阻擋。
5. 將金幣消耗放在卡片展示、島嶼紀念品與裝飾上。
6. 保留既有玩家存檔、訪客商品與已放置建築。
7. 第一版可在現有 `island.html` 架構內完成，不需立即拆成大型新系統。

## 4. 核心提案：世界城市明信片

將「今日訪客」改為「今日旅客」或「世界旅客」。

每次選定一座城市，玩家累計完成 3 個不同日的城市任務後，取得該城市卡片。

### 4.1 基本規則

- 同一座城市停留到收集完成，不每日隨機更換城市。
- 每天最多取得 1 枚該城市的護照章。
- 累計 3 枚護照章取得城市卡。
- 3 天不必連續。
- 某天未登入，進度不歸零。
- 答錯可重新挑戰，但同一天最多取得 1 枚章。
- 完成一座城市後，下一個有效日開始下一座城市。
- 第一輪不出重複城市，收集完整套後才進入複習輪。

### 4.2 三日學習節奏

#### 第 1 枚章：城市與國家

- 認識城市名稱、國家與國旗。
- 建議句型：`Paris is in France.`
- 題型可使用看圖選擇、城市與國家配對。

#### 第 2 枚章：代表地標

- 認識一個具代表性的地標。
- 建議句型：`The Eiffel Tower is in Paris.`
- 題型可使用聽力選擇、圖片配對。

#### 第 3 枚章：旅行會話

- 使用一個短而實用的旅行句型。
- 建議句型：`I want to visit Paris.`
- 題型可使用句子排序、聽力選擇或口說跟讀。

### 4.3 取得城市卡

取得第 3 枚章後，直接免費獲得城市卡，不另外收費。

理由：

- 卡片代表完成學習任務的成果。
- 不應因金幣不足而無法領取學習獎勵。
- 金幣回收應放在卡片的延伸展示與島嶼建設。

## 5. 城市卡內容

每張卡建議只放少量且可重複聆聽的內容：

- 城市英文名稱。
- 國家英文名稱與國旗。
- 一個代表地標。
- 一句核心英文句子。
- 英文語音播放按鈕。
- 取得日期。
- 卡片所屬地區，例如亞洲、歐洲、美洲。
- 是否已解鎖島嶼紀念品。

### 5.1 卡片範例

```text
🇫🇷 Paris
Country: France
Landmark: Eiffel Tower
The Eiffel Tower is in Paris. 🔊
Collected: 2026-07-15
```

## 7. 金幣回收機制

### 7.1 原則

優先採用以下類型：

- 玩家主動選擇。
- 消費後有看得見的成果。
- 不會破壞既有學習進度。
- 不會因數日未登入而受到懲罰。
- 能支撐長期或重複消費。

不建議第一版加入：

- 每日強制維修費。
- 離線稅或金幣自然消失。
- 連續登入中斷後章數歸零。
- 以隨機抽卡作為主要城市卡取得方式。
- 尚未集滿第一套前就出現重複城市卡。

### 7.2 城市卡免費，延伸內容收費

| 項目 | 建議價格 | 性質 |
|---|---:|---|
| 城市卡 | 免費 | 完成三日任務直接取得 |
| 普通相框 | 100 | 卡冊裝飾 |
| 城市紀念品 | 250～400 | 可放置於島上，增加美化 |
| 大型城市地標 | 600～1,000 | 唯一建築或高階裝飾 |
| 金色卡框 | 500 | 收藏展示，不產幣 |

### 7.3 城市紀念品範例

| 城市 | 中階紀念品 | 建議價格 | 大型地標 | 建議價格 |
|---|---|---:|---|---:|
| Taipei | 珍珠奶茶攤 | 300 | Taipei 101 模型 | 800 |
| Tokyo | 拉麵攤 | 300 | Tokyo Tower 模型 | 800 |
| London | 紅色電話亭 | 300 | Big Ben 模型 | 850 |
| Paris | Paris Café | 300 | Eiffel Tower 模型 | 850 |
| New York | 黃色計程車 | 350 | Statue of Liberty 模型 | 900 |
| Sydney | 衝浪小屋 | 300 | Opera House 模型 | 850 |

建議城市紀念品只提供美化，或提供極少量人口；不要再產生金幣，避免回收機制反而加劇通膨。

### 7.4 地區套卡獎勵

集滿某地區時可送免費展示建築：

- 亞洲套卡：亞洲旅行拱門。
- 歐洲套卡：歐洲廣場。
- 六大地區各至少一張：世界旅行噴泉。
- 完成 12 張：國際機場或世界博物館。

套卡獎勵應以美化與展示為主，不再提供大量金幣。

## 8. 其他建議的金幣回收方式

### 8.1 道路與小型景觀

增加可重複購買的低價裝飾：

- 道路：20～30 金幣。
- 路燈：40～60 金幣。
- 長椅：40～60 金幣。
- 花圃：50～80 金幣。
- 城市旗幟：80～120 金幣。

這類裝飾是穩定的長期回收機制，也能讓 15×15 地圖看起來更完整。

若每個裝飾都占用建築格，可能造成格數不足；可考慮：

1. 使用可放置但不計入主要建築數的裝飾層。
2. 道路改成地板樣式，不占用建築格。
3. 第一版先限制每種裝飾數量，降低渲染與存檔複雜度。

### 8.2 每週城市慶典

- 玩家可花 200～500 金幣舉辦一次城市慶典。
- 島上顯示旗幟、燈飾或煙火 3 天。
- 可暫時增加美化，但不要增加金幣收入。
- 慶典結束後保留「曾舉辦」紀錄或徽章。

此項屬於第二階段，不必和城市卡第一版同時推出。

### 8.3 建築拆除退款調整

目前拆除為全額退款，建議改為：

- 建造當天或短暫試用期內：100% 退款。
- 試用期結束後：70% 退款。
- 免費建築仍不退款。
- 舊版地圖 migration 或系統自動拆除仍維持 100% 退款。

目的：

- 保留兒童試蓋與反悔空間。
- 讓長期建造決策形成部分永久消耗。
- 不因版本升級或系統遷移懲罰玩家。

此項應先檢查三位學生目前的金幣與島嶼狀態，再決定是否立即上線。

## 9. 與現有功能的整合

### 9.1 保留島民委託板

島民委託板目前負責：

- 每日英文選擇題。
- 依答對題數發放金幣。
- 每完成 5 天給 1 張禮物券。

建議維持不變，讓兩個每日活動分工：

- 島民委託板：短期金幣與禮物券。
- 世界旅客：長期城市卡、英語文化與紀念品解鎖。

### 9.2 保留舊訪客商品

既有熱氣球、石像、花鐘及其 `visitorStock` 不應刪除。

建議處理方式：

- 已取得庫存與已放置建築全部保留。
- 在建築選單中改列為「經典訪客紀念品」。
- 新版世界城市系統使用新的資料欄位。
- 不重用或覆寫舊 `visitorStock` 的語意。

## 10. 建議資料結構

以下只是設計草案，實作時可依現有存檔格式調整：

```js
island.cityAlbum = {
  version: 1,
  currentCityId: "paris",
  currentStamps: 2,
  lastStampDate: "2026-07-11",
  routeIndex: 6,
  cards: {
    tokyo: {
      collectedAt: "2026-07-04",
      frame: "normal",
      souvenirBuilt: true,
      landmarkBuilt: false
    }
  },
  completedRegions: []
};
```

城市定義可獨立為常數：

```js
const WORLD_CITIES = [
  {
    id: "paris",
    city: "Paris",
    country: "France",
    flag: "🇫🇷",
    region: "europe",
    landmark: "Eiffel Tower",
    sentence: "The Eiffel Tower is in Paris.",
    souvenirKey: "parisCafe",
    landmarkKey: "miniEiffel"
  }
];
```

### 10.1 防止同日重複領章

- 以 `lastStampDate` 判斷當日是否已領取。
- 重做題目可以練習，但不再增加章數。
- 使用既有 `todayStr()`，保持日期規則一致。

### 10.2 路線與重複保護

- 第一輪依固定或洗牌後保存的路線前進。
- 路線需寫入存檔，避免每天重新排序。
- 第一套未完成前不應出現重複城市。
- 完成第一套後，可進入「城市複習」並取得相框或熟練度，不再重複新增卡片。

## 11. UI 建議

### 11.1 島嶼主畫面按鈕

將：

```text
🛶 今日訪客
```

改成：

```text
✈️ 今日旅客
```

完成當日任務後顯示：

```text
✈️ 今日護照章 ✅
```

### 11.2 任務面板

面板頂端顯示：

```text
🇫🇷 Paris 之旅
護照章：● ● ○
再完成 1 天即可獲得城市卡
```

### 11.3 卡冊入口

島嶼頁新增：

```text
📕 世界城市卡冊 4/12
```

卡冊內可依地區分頁，未取得的城市只顯示剪影與 `???`，但可顯示下一座城市。

### 11.4 完成動畫

取得第 3 枚章時：

1. 顯示護照蓋章動畫。
2. 卡片翻面出現。
3. 播放城市名稱與核心句子。
4. 顯示「已解鎖島嶼紀念品」，但不強迫立即購買。

## 12. 數值與觀測建議

正式決定價格前，建議統計三位學生：

- 目前金幣餘額。
- 每日平均練習收入。
- 每日平均島嶼被動收入。
- 現有建築總數與生產型建築數。
- 最近 7 天實際消費金額。

初步價格目標：

- 中階玩家約 1～2 天收入可買一個小型紀念品。
- 約 3～5 天收入可買一座大型城市地標。
- 不應讓新玩家為第一個紀念品等待超過一週。
- 卡片永遠不因金幣不足而被扣留。

## 13. 分階段實作建議

### 第一階段：最小可用版本

- 建立 12 座城市資料。
- 今日訪客改為今日旅客。
- 每座城市累計 3 個不同日的章。
- 第 3 章免費取得卡片。
- 新增世界城市卡冊。
- 每張卡先解鎖 1 個中價紀念品。
- 保留舊訪客商品與舊存檔。

### 第二階段：經濟擴充

- 每城加入大型地標。
- 新增普通相框與金色相框。
- 新增道路、路燈、長椅、花圃。
- 評估拆除退款改為 70%。

### 第三階段：長期內容

- 地區套卡獎勵。
- 城市複習與卡片熟練度。
- 每週城市慶典。
- 擴充第二批城市。

## 14. 驗收條件

第一階段完成後應符合：

1. 同一天無法重複取得護照章。
2. 中斷數日後仍保留原章數。
3. 收集 3 個有效日後一定能免費取得城市卡。
4. 第一套未完成前不會出現重複城市。
5. 既有熱氣球、石像、花鐘庫存與建築不消失。
6. 舊存檔沒有 `cityAlbum` 時可安全建立預設值。
7. 卡片解鎖與紀念品購買分開處理。
8. 城市紀念品不產生大量金幣。
9. 雲端同步後，護照章與卡冊內容保持一致。
10. 手機版可以正常開啟任務面板與卡冊。

## 15. 請 Claude 審閱的問題

1. 目前 `island.html` 的單檔架構是否適合直接加入城市資料與卡冊 UI，還是應先拆出 `city_album.js`？
2. `kids_data.js`、`cloud_sync.js` 與島嶼存檔合併邏輯是否會遺漏新的 `cityAlbum` 深層欄位？
3. 目前雲端同步採用的時間判斷，是否足以避免手機與電腦同日重複領章？
4. 既有 `visitor`、`visitorStock` 應完整保留，還是需要一次性 migration？
5. 3 個有效日取得一張卡，是否符合目前每週五日的兒童訓練節奏？
6. 紀念品 250～400、地標 600～1,000 的價格，依目前三位學生實際收入是否合理？
7. 拆除退款從 100% 改成 70% 是否必要，或先靠城市裝飾與地標就足以回收金幣？
8. 城市紀念品若放在現有 15×15 格子中，是否會造成後期空間不足？
9. 卡片圖片應使用現有 emoji／CSS 先做第一版，還是直接製作統一風格的卡面與地標像素圖？
10. 第一階段有哪些功能應再縮小，以降低一次改動 `island.html` 的風險？

## 16. 建議決策

建議先採用以下版本：

- 12 座城市。
- 每座累計成功 3 天取得卡片。
- 不要求連續登入。
- 城市卡免費。
- 每張卡解鎖一個 300～400 金幣的紀念品。
- 第一版紀念品只增加美化，不產幣。
- 保留舊訪客商品與資料。
- 暫不立刻修改拆除退款，先觀察城市紀念品上線後的金幣消耗。
- 完成第一階段與實際觀測後，再決定大型地標、相框與道路系統。

此版本能先驗證孩子是否願意持續收集城市卡，也能避免同時修改過多島嶼經濟規則。

每個單元：概念圖 → 聽講解 → 例句 → 小測驗（領金幣 🪙）。順序由上往下，一個觀念花幾週都可以，複習單元把前面觀念組合起來用。
🏗️ 句子是什麼誰＋做什麼（主詞＋動詞）；直述/疑問/命令/驚嘆四種句型 🧸 名詞與 a/an/the一個/很多個（單複數）；a/an 第一次提到、the 你我都知道 🎭 代名詞家族I/me/my/mine 一家四口；位置不同穿不同衣服 ⚙️ 兩種動詞引擎be 動詞（是/在/狀態）vs 一般動詞（動作）——最重要的分水嶺 🏭 綜合複習：造句工廠把名詞、代名詞、be/一般動詞組成正確句子 🔁 現在簡單式習慣與事實（不是現在正在！）；三單 s 🔍 現在進行式現在正在做什麼；be + V-ing 是一組 📖 過去簡單式把事情放進「昨天盒子」；規則 -ed＋常用不規則 🛤️ 綜合複習：時間軸yesterday / every day / right now / later 四個站牌 🤖 問句與否定do/does/did 小幫手；not 的位置 🏷️ 描述員形容詞貼名詞、副詞貼動作、頻率副詞貼習慣 🗺️ 位置與時間空間介係詞（圖感）＋ at/on/in 時間金字塔 🌅 綜合複習：描述我的一天用時態＋描述詞＋介係詞說完整的一天 🌉 連接詞and/but/or/so/because 五座橋 🧰 好用的小幫手can（能力）＋There is/are（存在）＋will / be going to 入門；should/must 為補充 🧪 總複習：句子合體把全部觀念合體，寫短段落（自我介紹/日記）

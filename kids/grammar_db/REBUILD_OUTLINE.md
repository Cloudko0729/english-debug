# 兒童英語文法資料庫重建大綱

> 建立日期：2026-07-25  
> 範圍：F0–F7；F0–F3 細分為較小能力節點  
> 對應課程：2026 年 9 月至 2027 年 6 月十個月度主課  
> 目標：先避免根本誤解，再降低母語人士會察覺的突兀感，最後培養修改能力

---

## 1. 結論

建議重建「資料層」，但保留現有 `kids/grammar_core/` 中可用的例句、音檔、講稿與 SVG。

現有 12 個主單元加 4 個複習單元，適合當課程頁，卻不適合直接當能力資料庫：

- 一個單元同時包含太多概念，例如名詞、單複數與冠詞放在同一單元。
- 基礎較弱的孩子無法指出自己卡在哪一個微能力。
- 多數測驗是四選一，能辨識不代表能自然說出或寫出。
- 有些教學比喻過度簡化，之後可能造成新誤解。
- 缺少「正確但不自然」「語法可接受但語意不同」「英美皆可」等判定。

新版以「溝通意義＋句型限制＋自然用法＋錯誤後果」為核心，每一個微能力都能單獨診斷、教學、複習與記錄。

## 2. 成功標準

### 2.1 優先順序

1. **不改變核心意思**
   - 問句不能變直述句。
   - 否定不能漏掉。
   - 時間關係不能因時態錯誤而改變。
   - 代名詞指涉要清楚。
   - 單複數與數量不能造成事實誤判。

2. **不形成根本文法誤解**
   - 不把 `be` 解釋成中文的「是」。
   - 不把 `do/does/did` 當成有實際動作意思的主要動詞。
   - 不把現在簡單式理解成「此刻正在」。
   - 不把所有過去式都視為字尾加 `-ed`。
   - 不把 `a/an` 判斷簡化成只看第一個字母。

3. **降低母語人士會察覺的突兀感**
   - 使用自然語序、冠詞、介系詞與常用搭配。
   - 避免中文逐字翻譯。
   - 能選擇符合情境的時態、情態與連接方式。
   - 知道完整句、簡短回答與口語省略的差別。

4. **能自行修改**
   - 看得出問題屬於意思、句型、搭配或語體。
   - 能用檢查表修改短文，而不只重做選擇題。

### 2.2 錯誤嚴重度

| 等級 | 定義 | 例子 | 教學處理 |
|---|---|---|---|
| E0 意思失真 | 造成相反或錯誤事實 | `I don't went.`、漏掉 `not` | 立即修復，不推新文法 |
| E1 句型失控 | 母語人士需重新解析 | `She is play soccer.` | 回到句型骨架與對比練習 |
| E2 明顯突兀 | 意思可懂，但不自然 | `I very like it.` | 加自然搭配與語序練習 |
| E3 可接受差異 | 文法正確，屬語體或英美差異 | `at the weekend / on the weekend` | 標註差異，不判成錯誤 |

## 3. 分級架構

保留目前適性診斷的 F0–F7 大級別；F0–F3 另外以小數節點細分。診斷結果要記錄到微能力，不只留下單一總 band。

### F0｜英語起點

| 節點 | 能力目標 | 必須避免的誤解 |
|---|---|---|
| F0.1 | 分辨單字、片語、子句與完整句；找到「誰／什麼＋發生什麼」 | 看到一串單字就當成句子 |
| F0.2 | `I am / you are / he is` 等最短 `be` 肯定句 | 依中文有沒有「是」決定 `be` |
| F0.3 | 用 `be` 表示身分、狀態與位置 | 把形容詞或位置當動詞 |
| F0.4 | 單數名詞、複數 `-s/-es`、數字＋複數名詞 | `two book`、`a books` |
| F0.5 | `a/an` 依下一個聲音選擇；專有名詞通常不加 | 只看母音字母、不看聲音 |

### F1｜A1 起步

| 節點 | 能力目標 | 必須避免的誤解 |
|---|---|---|
| F1.1 | 主詞代名詞與 `be` 一致：`I am / she is / they are` | 每個主詞都用 `is` |
| F1.2 | 一般動詞肯定句：主詞＋動詞＋受詞／補充資訊 | 在一般動詞前任意加 `be` |
| F1.3 | 分辨 `be` 述語與一般動詞述語 | 把「一個句子只能有一個動詞」當絕對規則 |
| F1.4 | `be` 的否定、問句與短答 | `Do you hungry?` |
| F1.5 | `do/does` 的問句、否定與後接原形 | `Does she likes...?` |
| F1.6 | 基本 `Wh-` 問句：人物、物品、地點、時間、原因 | 只會把 `what` 放句首，後面語序不變 |

### F2｜A1 發展

| 節點 | 能力目標 | 必須避免的誤解 |
|---|---|---|
| F2.1 | 現在簡單式表習慣、反覆與事實；第三人稱單數 | 把現在簡單式理解為此刻正在 |
| F2.2 | 頻率副詞在一般動詞前、`be` 後的常見位置 | `I play usually soccer.` |
| F2.3 | 現在進行式 `be + V-ing` 表此刻或暫時狀況 | 漏 `be` 或使用 `be + 原形` |
| F2.4 | 現在簡單與現在進行的意義對比 | 只看時間詞做機械配對 |
| F2.5 | 常見狀態動詞：`like, want, know, need` 通常不用進行式 | `I am knowing.` |
| F2.6 | 主格、受格、所有格形容詞、所有格代名詞 | `Teacher helps I.`、`mine book` |
| F2.7 | `there is/are`、可數／不可數、`some/any` 入門 | 用 `have` 直翻「有」 |

### F3｜A1 穩定

| 節點 | 能力目標 | 必須避免的誤解 |
|---|---|---|
| F3.1 | 過去式 `was/were` 的狀態與位置 | `did be` 或主詞配錯 |
| F3.2 | 規則與高頻不規則過去式 | 所有動詞只加 `-ed` |
| F3.3 | `did` 問句與否定後接原形 | `didn't went` |
| F3.4 | 地點與時間介系詞；先理解關係再學固定搭配 | 每個中文「在」都翻成 `in` |
| F3.5 | `and/but/or/because/so` 表示不同邏輯關係 | 同時使用 `because ... so ...` |
| F3.6 | `can`、`will`、`be going to` 的基本意思與後接原形 | 把三者都當相同的「會」 |

### F4｜A1+／A2 起步

- 過去進行式與 `when/while`
- 形容詞、副詞與自然位置
- 比較級／最高級基礎
- `much/many/a few/a little/fewer/less`
- `should/must/have to/may/might` 的功能與強度
- 高頻 `to + V`、`V-ing` 搭配

### F5｜A2 基礎

- 現在完成式的經驗與目前結果
- `ever/never/already/yet/since/for`
- 現在完成式與過去簡單式
- 第一條件句
- `who/which/that/where` 限定關係子句
- 反身代名詞、代名詞指涉與避免歧義

### F6｜A2+ 橋接

- 過去、現在完成與時間標記的穩定選用
- 主動／被動：先做流程與資訊焦點
- 未來形式：安排、意圖、預測
- expanded noun phrases 與補充資訊
- 引述來源：`said that / according to`
- 句內與段內 cohesion

### F7｜B1- 準備

- 關係子句深化與先行詞清楚度
- 情態動詞的確定程度與推論
- 正式／非正式語體
- 跨句代名詞與連接語
- 冒號、分號、破折號、括號與連字號
- 找出「文法正確但突兀或含糊」的句子並修改

## 5. 每個文法節點的資料格式

```json
{
  "id": "F1.5-do-does",
  "band": "F1",
  "microLevel": 5,
  "titleZh": "do / does 問句與否定",
  "communicativeGoal": "詢問或否定平常的動作與喜好",
  "prerequisites": ["F1.2-action-affirmative"],
  "meaning": {},
  "form": {},
  "usageLimits": [],
  "naturalExamples": [],
  "contrastPairs": [],
  "chineseTransferBugs": [],
  "acceptableVariants": [],
  "britishAmericanNotes": [],
  "diagnosticItems": [],
  "productionTasks": [],
  "revisionChecks": [],
  "diagramRef": null,
  "audio": {}
}
```

### 每個節點最低內容量

- 4 個自然例句：生活、對話、敘事、寫作各一
- 2 組最小對比：形式相近但意思或正確性不同
- 2 個中文直翻 bug
- 1 組四至六句短對話
- 3 題辨識：形式、意思、自然度各一
- 2 題產出：口說一句、寫作一句
- 1 個修訂任務：修改短文中的錯誤
- 所有例句、對話與題幹均有預處理音檔

### 句子判定不能只有對／錯

每個候選句需支援四種標記：

- `natural`：自然且符合本節點目標
- `acceptable`：文法可接受，但受語境或語體限制
- `awkward`：意思清楚，但母語人士會覺得突兀
- `misleading`：可能造成根本誤解或改變原意

## 6. 文法示意圖方案

### 6.1 需要生成，但不是每個節點都生成

示意圖只用於「空間位置、句子結構、時間關係、選擇流程」比文字明顯更清楚的概念。建議約 14 組核心 SVG，可供多個節點共用。

| 圖組 | 用途 |
|---|---|
| 句子槽位圖 | 主詞、動詞、受詞、補語與可移動資訊 |
| 名詞決策樹 | 可數／不可數、單數／複數、限定詞 |
| a/an 聲音入口圖 | 依聲音分流，包含 `an hour / a university` |
| 代名詞位置圖 | 主格、受格、所有格與指涉箭頭 |
| 述語選擇圖 | `be + noun/adjective/place` 與一般動詞述語 |
| 問句轉換圖 | `be` 前移與 `do/does/did + 原形` 兩條路 |
| 時態／體時間軸 | 習慣、正在、已結束、與現在有關 |
| 頻率位置圖 | 一般動詞前、`be` 後 |
| 數量詞矩陣 | 可數／不可數 × 肯定／疑問／否定 |
| 比較刻度圖 | 原級、比較級、最高級與比較對象 |
| 情態強度梯 | `might → may → should → must`，並說明不是固定百分比 |
| 連接詞關係圖 | 添加、轉折、選擇、原因、結果 |
| 關係子句附著圖 | 補充資訊連到正確先行詞 |
| 主動／被動焦點切換圖 | 同一事件改變資訊焦點，不只交換位置 |
| 段落銜接圖 | 代名詞、連接語、重複關鍵詞與段落流向 |

### 6.2 圖像技術原則

- 使用 HTML／inline SVG，不使用含文字的 AI 點陣圖。
- 手機寬度可讀，文字不得小於實際顯示約 14px。
- 每張圖都有文字版說明與 `aria-label`。
- 正確與錯誤不能只靠紅綠色辨識。
- 圖中的例句必須從資料庫引用，避免圖與課文內容不同步。
- 一張圖只處理一個核心決策，不塞完整文法表。

### 6.3 現有圖需要修正的兩個例子

- `u2` 圖目前寫成 `an → 母音開頭 (a/e/i/o/u)`，需改成「母音聲音」，並加入 `an hour / a university`。
- `u4` 的「一台車一顆引擎」可保留為入門提醒，但資料庫不可把它當絕對規則；後續要改為「一句主要子句有一個完整述語／動詞片語」，才能容納 `is playing`、`can swim`、`has finished`。

## 7. 自然度與正確性審查

### 7.1 每筆英文至少檢查

1. 目標意思是否與中文提示一致。
2. 單獨看是否自然，放進指定情境是否仍自然。
3. 是否有更常見的母語用法。
4. 英式與美式是否都可接受，或需要註明差異。
5. 錯誤選項是否真的錯，而非只是另一個合理答案。
6. 自動批改是否接受合理的大小寫、標點、縮寫與答案變體。

### 7.2 內容審查流程

- 第一輪：資料結構與規則一致性。
- 第二輪：逐句自然度與語意審查。
- 第三輪：用最小對比確認孩子真的理解差異。
- 第四輪：完整跑過辨識、口說、寫作與修訂流程。
- 第五輪：音檔文字、JSON 文字與畫面文字三方一致。

## 8. 舊資料沿用與淘汰

### 可沿用

- `grammar_core` 的頁面版型、音訊播放器與進度機制。
- 大部分自然例句與中文直翻提醒。
- 16 個既有課程入口與四個複習站概念。
- 可修正後重用的 SVG 結構。
- 既有 Kokoro 預處理音檔流程。

### 需要重寫或拆分

- `u1`：完整句規則需清楚處理命令句與口語片段。
- `u2`：名詞、單複數、a/an、the 拆成獨立微能力。
- `u3`：代名詞依位置拆分，不一次要求完整變化表。
- `u4`：改寫「兩種引擎」的絕對說法。
- `u8`：`be` 問句與一般動詞問句應分流。
- `u9`：形容詞、副詞、頻率副詞拆開。
- `u10`：空間介系詞與時間介系詞拆開。
- `u12`：`can`、there、未來式與其他 modals 拆開。
- 只靠四選一即可通關的精熟判定。

## 9. 建置順序

### 第一階段：F0–F3

1. 建立 schema、manifest 與 validator。
2. 建立 24 個基礎微能力節點。
3. 建立自然例句、最小對比、中文直翻 bug 與可接受變體。
4. 建立基礎診斷題與產出題。
5. 生成 8–10 張基礎 SVG。
6. 產生預處理音檔並解碼驗證。

### 第二階段：F4–F7

1. 建立比較、數量、modals、完成式、條件句、關係子句與被動。
2. 加入自然度、語體與英美差異。
3. 加入段落 cohesion 與修改任務。
4. 生成剩餘 5–6 張結構圖。

### 第三階段：課程整合

1. 月初診斷輸出微能力缺口。
2. 依缺口決定新課、橋接或複習。
3. 每週五天新進度、兩天累積複習。
4. 只把家長頁需要的摘要寫入 Google Sheets 鏡像；逐題明細留在本機與 Supabase。

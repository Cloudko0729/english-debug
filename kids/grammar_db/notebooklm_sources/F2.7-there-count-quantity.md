## 這堂課要教什麼

描述存在，並搭配單複數、some 與 any。

句型公式：**there is + singular/uncountable; there are + plural**

今天學完，小朋友要能自己造一句像這樣的話：
「There is a book on the desk.」

## 情境對話（可以直接當開場小劇場）

A: Is there any juice?
B: Yes, there is some juice in the fridge.
A: Are there any cups?
B: Yes, there are four cups on the table.

請用這段對話當開場，營造真實生活情境，再帶出文法規則。

## 自然例句

1. There is a book on the desk.
2. There are three books on the desk.
3. There is some water in the bottle.
4. Are there any questions?

## 常見錯誤對照（請用「你猜猜看哪句對」的口吻帶過）

- ❌ There have a park near my house. → ✅ There is a park near my house.
  （英文存在句使用 there is，不直翻中文的「有」成 have。）
- ❌ There is three apples. → ✅ There are three apples.
  （複數 apples 搭配 are。）

## 中文母語者最容易犯的錯（請特別強調，因為是中文直翻習慣造成的）

1. 「冰箱裡有一些牛奶。」常被說成 ❌ There are some milk in the fridge.
   正確：✅ There is some milk in the fridge.
   原因：milk 是不可數名詞，搭配 is。

2. 「沒有任何問題。」常被說成 ❌ There aren't some questions.
   正確：✅ There aren't any questions.
   原因：一般否定句常使用 any。

# 第一條件句 First Conditional — NotebookLM 來源文件

> 用途：把這份文件整份貼進 NotebookLM 的來源（Source），再請它產生 Audio Overview（podcast）與 Video Overview。
> 目標聽眾：國小中年級英文學習者，中文為母語。語氣請活潑、口語、像哥哥姊姊在聊天教學，不要念條列項目。
> 本課情境主題：經驗、選擇與條件

## 這堂課要教什麼

說出「如果⋯⋯就會⋯⋯」這種有可能發生的事。

句型公式：**if + present simple, will/can + base verb**

今天學完，小朋友要能自己造一句像這樣的話：
「If it rains, we will stay inside.」

## 情境對話（可以直接當開場小劇場）

A: What will we do if it rains?
B: If it rains, we will move the picnic inside.
A: Can everyone still come?
B: Yes. We can meet in the gym if the park is wet.

請用這段對話當開場，營造真實生活情境，再帶出文法規則。

## 自然例句

1. If it rains, we will stay inside.
2. If you study, you will learn more.
3. I will call you if I need help.
4. If we leave now, we can catch the bus.

## 常見錯誤對照（請用「你猜猜看哪句對」的口吻帶過）

- ❌ If it will rain, we will stay inside. → ✅ If it rains, we will stay inside.
  （第一條件句的 if 子句通常使用現在簡單式。）
- ❌ If you will study, you pass the test. → ✅ If you study, you will have a better chance of passing the test.
  （條件與結果的形式要完整，且避免把結果說得不合理地絕對。）

## 中文母語者最容易犯的錯（請特別強調，因為是中文直翻習慣造成的）

1. 「如果你早點睡，明天會感覺好一點。」常被說成 ❌ If you will sleep early, you feel better tomorrow.
   正確：✅ If you sleep early, you will feel better tomorrow.
   原因：if 子句用現在式，結果使用 will。

2. 「如果我們錯過公車，可以走路。」常被說成 ❌ If we miss the bus, we can to walk.
   正確：✅ If we miss the bus, we can walk.
   原因：can 後接原形。

- 口說任務：Say what you will do if it rains tomorrow.

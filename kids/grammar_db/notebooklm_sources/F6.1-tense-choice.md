# 跨句時態選擇 Tense Choice Across Sentences — NotebookLM 來源文件

> 用途：把這份文件整份貼進 NotebookLM 的來源（Source），再請它產生 Audio Overview（podcast）與 Video Overview。
> 目標聽眾：國小中年級英文學習者，中文為母語。語氣請活潑、口語、像哥哥姊姊在聊天教學，不要念條列項目。
> 本課情境主題：科學實驗、流程與報告

## 這堂課要教什麼

依事件時間、背景與目前關聯，在短文中維持清楚一致的時態。

句型公式：**choose tense from communicative timeline, not one keyword**

今天學完，小朋友要能自己造一句像這樣的話：
「I was walking home when I found the key.」

## 情境對話（可以直接當開場小劇場）

A: How did you find the old map?
B: I was cleaning a shelf when a box fell open.
A: What have you done since then?
B: I have compared the map with two newer maps.

請用這段對話當開場，營造真實生活情境，再帶出文法規則。

## 自然例句

1. I was walking home when I found the key.
2. We have kept the key since that day.
3. The box was locked, so we asked a teacher for help.
4. Now we are studying the map inside it.

## 常見錯誤對照（請用「你猜猜看哪句對」的口吻帶過）

- ❌ Yesterday we find a key and now we kept it. → ✅ Yesterday we found a key, and we have kept it since then.
  （已結束事件用 found；從過去持續到現在用 have kept。）
- ❌ I was opening the box, and I saw an old map inside. → ✅ I opened the box and saw an old map inside.
  （兩個依序完成的主要事件通常都用過去簡單式。）

## 中文母語者最容易犯的錯（請特別強調，因為是中文直翻習慣造成的）

1. 「我正在回家時開始下雨，所以我跑到商店。」常被說成 ❌ I walked home when it was starting to rain, so I run to a store.
   正確：✅ I was walking home when it started to rain, so I ran to a store.
   原因：背景動作用過去進行，短事件與後續事件用過去簡單式。

2. 「我們從星期一起就在做這份報告。」常被說成 ❌ We worked on this report since Monday.
   正確：✅ We have worked on this report since Monday.
   原因：since Monday 連到現在時使用現在完成式。

## 小任務（podcast 結尾可以邀請小朋友一起做）

- 口說任務：Tell a short story with a background action and a main event.
- 寫作任務：Write three connected sentences using past and present perfect clearly.

## 給 NotebookLM 的額外提示

- 請控制長度在 3-5 分鐘（podcast）或 2-3 分鐘（影片），適合小學生的專注長度。
- 可以用遊戲化的開場（例如當小偵探、闖關、解謎）吸引注意力。
- 請避免使用過於學術的文法術語，改用小學生聽得懂的說法。
- 結尾請重複一次今天的句型公式，加深印象。

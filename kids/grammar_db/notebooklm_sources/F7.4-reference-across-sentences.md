# 跨句指涉與避免含糊 Reference across Sentences — NotebookLM 來源文件

> 用途：把這份文件整份貼進 NotebookLM 的來源（Source），再請它產生 Audio Overview（podcast）與 Video Overview。
> 目標聽眾：國小中年級英文學習者，中文為母語。語氣請活潑、口語、像哥哥姊姊在聊天教學，不要念條列項目。
> 本課情境主題：簡報、文章修改與自然表達

## 這堂課要教什麼

讓 it、they、this、these 等清楚指向前文，必要時重複關鍵名詞。

句型公式：**pronoun/demonstrative + unambiguous antecedent**

今天學完，小朋友要能自己造一句像這樣的話：
「The bridge had a loose board. This problem made it unsafe.」

## 情境對話（可以直接當開場小劇場）

A: Why is this sentence unclear?
B: The pronoun "it" could refer to two different things.
A: How can we fix it?
B: We can repeat the key noun or use a clearer noun phrase.

請用這段對話當開場，營造真實生活情境，再帶出文法規則。

## 自然例句

1. The bridge had a loose board. This problem made it unsafe.
2. Mia interviewed two nurses. They described the same issue.
3. We changed the bus route. The new route reduced travel time.
4. The report and the map disagreed, so we checked both sources.

## 常見錯誤對照（請用「你猜猜看哪句對」的口吻帶過）

- ❌ The map was beside the report, but it was outdated. → ✅ The map was beside the report, but the map was outdated.
  （it 可能指 map 或 report；重複名詞可消除歧義。）
- ❌ We moved the meeting online. This was helpful. → ✅ We moved the meeting online. This change helped more students attend.
  （this 後補上概括名詞 change，資訊更清楚。）

## 中文母語者最容易犯的錯（請特別強調，因為是中文直翻習慣造成的）

1. 「John 告訴 Peter，他需要更多時間。」常被說成 ❌ John told Peter that he needed more time.
   正確：✅ John told Peter, "I need more time."
   原因：原句 he 指涉不清；直接引語可明確指出 John。

2. 「設備壞了。這造成延誤。」常被說成 ❌ The device broke. This caused a delay.
   正確：✅ The device broke. This failure caused a delay.
   原因：原句可接受；正式說明加入 failure 更精確。

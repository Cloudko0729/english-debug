# 修改自然度與語意 Editing for Naturalness and Meaning — NotebookLM 來源文件

> 用途：把這份文件整份貼進 NotebookLM 的來源（Source），再請它產生 Audio Overview（podcast）與 Video Overview。
> 目標聽眾：國小中年級英文學習者，中文為母語。語氣請活潑、口語、像哥哥姊姊在聊天教學，不要念條列項目。
> 本課情境主題：簡報、文章修改與自然表達

## 這堂課要教什麼

找出文法正確性之外的語序、贅字、搭配與含糊問題。

句型公式：**meaning first, then structure, collocation, and register**

今天學完，小朋友要能自己造一句像這樣的話：
「I really like this book.」

## 情境對話（可以直接當開場小劇場）

A: Is this sentence understandable?
B: Yes, but "I very like it" sounds unnatural.
A: How should we revise it?
B: We should say, "I really like it."

請用這段對話當開場，營造真實生活情境，再帶出文法規則。

## 自然例句

1. I really like this book.
2. We discussed the problem after class.
3. Please enter the room quietly.
4. The results clearly support our plan.

## 常見錯誤對照（請用「你猜猜看哪句對」的口吻帶過）

- ❌ I very like this book. → ✅ I really like this book.
  （very 通常不直接修飾動詞 like；使用 really。）
- ❌ We discussed about the problem. → ✅ We discussed the problem.
  （discuss 直接接受詞，不加 about。）

## 中文母語者最容易犯的錯（請特別強調，因為是中文直翻習慣造成的）

1. 「請安靜地進入房間。」常被說成 ❌ Please enter into the room quietly.
   正確：✅ Please enter the room quietly.
   原因：enter 在此可直接接受詞 room，into 顯得多餘。

2. 「我們返回回學校。」常被說成 ❌ We returned back to school.
   正確：✅ We returned to school.
   原因：return 已包含「回」的意思，back 通常多餘。

STEP ①

單字 Vocabulary（含發音）

這些就是連接詞，學會它們就能把短句變長句。

STEP ②

文法 Grammar：連接詞怎麼用

連接詞把兩個想法連成一句。依意思分四類：

① 原因 / 結果：because（因為）/ so（所以）

I stayed home because it rained. 我因為下雨待在家。
It rained, so I stayed home. 下雨了，所以我待在家。

② 轉折：but（但是）/ although（雖然）

Although it was cold, we went out. 雖然很冷，我們還是出門了。

③ 時間：when（當）/ before（之前）/ after（之後）

Call me when you arrive. 你到的時候打給我。
Wash your hands before you eat. 吃飯前先洗手。

④ 條件：if（如果）

if 子句用現在式，主句用 will（未來）。
If it rains, we will stay home. 如果下雨，我們就待在家。

⚠️ 最常犯的錯

✗ Because it rained, so I stayed home. → ✓ 二選一（because 和 so 不能同句一起用）
✗ Although…, but… → ✓ 二選一（although 和 but 不能同句一起用）
✗ If it will rain… → ✓ If it rains…（if 子句用現在式）

整體方向成立；核心要避免「重複花錢點按」，讓好感度同時包含日常習慣、文化選擇與英文挑戰。建議數值如下。

## 1. 好感度與金幣

### 等級門檻

| 等級 | 累積好感度 | 解鎖 |
|---|---:|---|
| Lv0 | 0 | 基礎城市卡、城市交流 |
| Lv1 | 50 | 城市介紹＋第一段語音 |
| Lv2 | 125 | 文化卡 |
| Lv3 | 225 | 進階景點卡 |
| Lv4 | 350 | 人物卡 |
| Lv5 | 500 | 金卡外框、徽章、城市稱號 |

每座城市每日最多取得 **35 點**，因此最快也要約 15 個活躍日；正常漏玩或答錯約 17～21 日。

### 動作與成本

| 動作 | 成本 | 好感度 | 限制 |
|---|---:|---:|---|
| 每日打招呼 | 免費 | +3 | 每城每日 1 次 |
| 小禮物 | 40 | +4；偏好 +6 | 禮物好感每日合計最多 12 |
| 標準禮物 | 80 | +7；偏好 +11 | 同上 |
| 精緻禮物 | 140 | +10；偏好 +12 | 偏好不宜加倍，避免付費碾壓 |
| 交流活動：答對 1 題 | 100 | +8 | 每城每日首次活動有好感 |
| 交流活動：答對 2 題 | 100 | +14 | 同上 |
| 交流活動：答對 3 題 | 100 | +20 | 同上 |
| 重玩交流活動 | 免費 | 0 | 可練習，但不能刷好感 |

典型路線：15 個活躍日，每日打招呼、送 80 金幣偏好禮物、完成滿分交流：

- 好感度：`15 × (3 + 11 + 20) = 510`
- 金幣：`15 × (80 + 100) = 2,700`
- 日曆時間：約 2～3 週

全帳號再加一個「交流好感每日總上限 100」，避免玩家同一天把大量城市一起灌滿。

## 2. 偏好禮物：學習味與驚喜感

不要直接顯示答案。每座城市提供一句英文線索，例如：

> People here enjoy a warm drink during afternoon tea.

送出後才揭曉：

- 喜歡：角色做特殊反應，出現一句文化說明＋單字語音。
- 普通：仍加基本好感，避免孩子因猜錯受挫。
- 每座城市可有 2～3 個接受禮物，但只有一個「本週最愛」。
- 第一次發現偏好時，登錄進「城市喜好圖鑑」，並給一次性 +5 探索獎勵。
- 每週輪替線索或偏好分類，避免永遠死背同一答案。
- 避免「東京＝拉麵」式過度簡化；文案應寫成「這座城市常見／有名」，不要寫成所有居民都喜歡。

12 城市範例：

| 城市 | 偏好禮物 | 英文學習點 |
|---|---|---|
| 東京 | 拉麵模型 | noodles / bowl |
| 首爾 | 韓紙書籤 | paper / bookmark |
| 台北 | 珍珠奶茶 | bubble tea / straw |
| 北京 | 風箏 | kite / fly |
| 新加坡 | 蘭花 | orchid / flower |
| 曼谷 | 茉莉花環 | jasmine / garland |
| 倫敦 | 下午茶組 | tea / teacup |
| 巴黎 | 法棍 | bread / bakery |
| 羅馬 | 義式冰淇淋 | gelato / cold |
| 紐約 | 百吉餅 | bagel / breakfast |
| 雪梨 | 衝浪板模型 | surfboard / wave |
| 開羅 | 紙莎草書籤 | papyrus / writing |

實際上線前需做文化審稿，尤其人物、宗教及傳統服飾內容。

## 3. 交流活動

每次固定 3 題、約 60～90 秒，從三個現有來源各抽一題：

1. **城市卡句型**：聽音選句、句子排序、替換城市或景點名稱。
2. **兒童 wordbank**：圖片配字、聽音選圖、分類配對。
3. **本週單字**：填空、二選一、把週單字放入城市情境。

活動形式每次隨機組合：

- 城市導遊：選出正確介紹句。
- 行李打包：依線索選適合物品。
- 文化配對：把食物、景點、活動配到正確圖片。
- 小小翻譯員：補完簡短對話。
- 聽力快問快答：播放語音後選圖片。
- 明信片：拖曳單字完成一張兩句英文卡片。

題目需具備題型、難度、來源、正解、干擾項、語音及文化說明。錯題立即教學；活動結束後可免費重練，但好感只結算第一次。

## 4. 進階卡規格與內容產製

每張卡統一欄位：

- `card_id`
- `city_id`
- `type`：culture / landmark / person
- 中英文標題
- 主圖與圖片替代文字
- 兒童英文句，建議 6～12 字
- 中文解釋
- 2～4 個重點單字
- 英文語音、語速標記
- 一則 30～50 字文化小知識
- 一題理解題及答案
- 解鎖等級
- 內容來源／審稿狀態
- 人物的年代、領域及選用理由

共 `12 城市 × 3 張 = 36 張`。我可以直接產出完整第一版內容、英文分級、題目和結構化資料；但正式上線應由團隊指定城市名單與目標年齡後，再經英文教學審稿及文化／史實查核。人物卡優先選已故、具教育價值且與城市關聯明確的人物，避免在世政治人物與爭議性代表。

## 5. 寵物完整計畫

### 經濟與成長

- 第一隻寵物：完成新手任務後免費領養；其他品種 500 金幣。
- 每日正常餵食：20 金幣，或消耗 1 份島上食物。
- 零金幣的「摸摸／玩耍」每日一次，恢復少量心情但不能代替餵食。
- 幼年 → 成長期：累積 5 個照顧日。
- 成長期 → 成年：累積 14 個照顧日。
- 「照顧日」需當天餵食，不能用一次大量餵食補進度。
- 成年後每 7 個照顧日解鎖表情、動作或卡冊貼紙，不增加島嶼格子。

### 狀態機

- **開心**：24 小時內餵過，且最近有互動。
- **正常**：24～48 小時未餵。
- **餓**：48～72 小時未餵；移動變慢，顯示食物提示。
- **難過**：超過 72 小時；停止成長、坐下或睡覺。
- 餵食後直接恢復正常，再玩耍一次回到開心。
- 不死亡、不逃走、不倒退進化、不清除連續紀錄；避免對兒童造成壓力。

### 精靈圖層

寵物應是獨立的 `pet layer/entity`，不進建築網格：

- 使用島嶼可行走遮罩或預設路點。
- 只在空地路徑間漫遊，不參與建築碰撞計算。
- 建築前後以 `y-sort` 或深度值处理遮擋。
- 狀態：idle、walk、eat、happy、sleep、sad。
- 低效能裝置只顯示一隻，降低動畫幀率；離線時不模擬完整路徑，只依時間戳更新狀態。
- 點擊寵物開啟浮層面板，餵食與換裝都不占島格。

### 是否互搶金幣

若第一隻仍收 500，會與城市養成的 2,700 金幣形成明顯競爭，因此建議第一隻任務免費。日餵 20 在三週只需 420，約為單城 Lv5 成本的 16%，可以接受。

不要讓寵物餵食直接增加城市好感，否則兩套系統會變成彼此必做。可做低壓交集：城市 Lv2 解鎖一款「城市風格寵物配件」，僅外觀收藏，不增加數值。

## 6. 第一階段最小可玩版本

第一階段只做：

- 3 座城市。
- Lv0～Lv3，門檻仍採 50／125／225。
- 每日打招呼、標準禮物、三題交流活動。
- 每城一個隱藏偏好禮物。
- 每城文化卡＋景點卡，共 6 張進階卡。
- 卡冊 UI、每日上限、好感進度條。
- 一種免費寵物。
- 餵食、開心／正常／餓／難過、幼年到成長期。
- 島上 idle／walk／eat／sleep 四種動畫，不占格子。
- 基本事件紀錄：活動答對率、偏好發現率、到 Lv2/Lv3 所需天數、金幣消耗、寵物餵食留存。

先驗證玩家是否願意持續進行城市交流，以及城市與寵物是否造成金幣壓力；人物卡、Lv4～5、寵物成年與裝扮可放第二階段。

# 小六文法課程重新規劃（草案，請覆審）

對象：台灣小孩，2026/9 升小六，2027/9 升國中。搭配已排好的 48 週單字計畫。
取代現行「每月固定 1~2 個文法主題」的排法。

## 設計原則（家長最新指示已納入）
1. **不求一年學完所有文法**——著重「基本觀念的根基」，學穩再前進，寧慢勿快
2. 常用優先、觀念建立為主，不學複雜度高的（不教：被動、關係子句、間接引述、完成式家族）
3. 課程是「順序」不是「進度表」：每個觀念不限週數，滾動式複習（spiral review）佔比高
4. 參考英美教學法：
   - 美式：句子 = 誰＋做什麼；時態用時間軸圖；詞性用顏色標記
   - 英式 KS2：word classes、四種句型
   - Grammar in Use 式：一頁一觀念、用法先於術語、大量例句
5. 每單元配：概念圖（SVG）＋ 中文講解 Podcast（穿插英文例句）＋ 例句集 ＋ 小測驗

## 根基單元序列（12 個核心單元＋4 個綜合複習，共 16；一年走不完也沒關係）
| # | 單元 | 核心觀念 | 建議最少週數 |
|---|------|----------|--------------|
| U1 | 句子是什麼 | 誰＋做什麼（主詞+動詞）；四種句型 | 2-3 |
| U2 | 名詞與 a/an/the | 單複數；冠詞的直覺 | 2-3 |
| U3 | 代名詞家族 | I/me/my/mine 表格 | 2 |
| U4 | 兩種動詞引擎 | be 動詞 vs 一般動詞（最重要的分水嶺） | 3 |
| R1 | 綜合複習：造句工廠 | U1-U4 組合造句 | 2 |
| U5 | 現在簡單式 | 事實與習慣；三單 s | 3 |
| U6 | 過去簡單式 | 昨天的故事；-ed＋常用不規則 | 3 |
| U7 | 未來 | will / be going to | 2 |
| R2 | 綜合複習：時間軸 | 三大時態在一條時間軸上 | 2-3 |
| U8 | 問句與否定 | do/does/did 小幫手；not 的位置 | 3 |
| U9 | 描述員 | 形容詞、副詞、頻率（always~never） | 2-3 |
| U10 | 位置與時間 | 介係詞空間圖；at/on/in 金字塔 | 2 |
| R3 | 綜合複習：描述我的一天 | 用 U5-U10 寫/說一段話 | 2 |
| U11 | 連接詞 | and/but/or/so/because | 2 |
| U12 | 好用的小幫手 | can/should/must＋There is/are | 2-3 |
| R4 | 總複習：句子合體 | 全部觀念寫短段落 | 2+ |

合計最少約 38 週；走到哪算到哪，R4 之後有餘裕才碰「現在進行式」等下一層。

## 請覆審（直接回覆文字，精簡，格式「UxX 改成…」）
1. 這 12＋4 的取捨對「根基」來說對不對？有沒有更該進前 12 的觀念？
2. 順序有沒有問題？（現在進行式被移出核心，對台灣國中銜接會不會吃虧？）
3. 概念圖：請對每個單元給一句「圖要畫什麼」（例如 R2：一條時間軸，昨天/現在/明天三個站牌）
4. Podcast 講解（每集 2-4 分鐘、中文講觀念+英文例句）：各單元最該講透的一個點是什麼？

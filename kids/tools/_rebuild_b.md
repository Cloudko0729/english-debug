# 任務：中文維修詞 → 英語詞彙表（80~120 條）
讀 kids/tools/_zh_terms.txt（10 萬筆維修紀錄＋223 封信的中文高頻詞，格式：詞<TAB>次數<TAB>樣本句）。
使用者：半導體測試設備維修公司窗口。挑「他工作天天講、但可能不知道英文怎麼說」的詞：
{"zh":"備品","en":"spare unit / spare part","example":"We will ship a spare unit first."}
- 略過 n-gram 碎片（修完成結/品交換作）、公司名（京元/好修/沛頓）、人名地名
- 一個中文詞可給 1~2 個英文說法（斜線分隔）；example 要能直接用在信件/對話
- 優先：返修/待驗/結案/借出/親取/上電/量測/子板/特殊板型/追加/催料 等流程詞
寫檔 kids/tools/_rebuild_zh.json：{"zh_to_en":[…]}。回覆只要統計。直接產完整內容，不要佔位符，不要先探索其他檔案。

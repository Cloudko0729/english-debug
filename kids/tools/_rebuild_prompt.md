# 任務：獨立重建維修/商用英語詞庫（含中文詞→英語轉換）

你有三份詞頻檔（都在 kids/tools/，格式：詞<TAB>次數<TAB>樣本句）：
1. `_mail_words.txt`：223 封真實工作信的英文高頻字
2. `_repair_terms.txt`：10 萬筆維修工程紀錄的英文詞頻（UNIGRAM+BIGRAM 兩區）
3. `_zh_terms.txt`：同批資料的**中文**高頻詞 ← 重點新素材

使用者：半導體測試設備維修公司窗口。請用你自己的判斷獨立建庫（不要參考 adult/ 下的既有詞表，這是刻意的獨立重建，之後會做比對）。

## 輸出 A：英文詞庫（250~350 條）
從檔案 1、2 挑有教學價值的：{"en":"…","zh":"…","kind":"business"|"repair","level":1|2|3}
- 略過：人名、公司名、信尾免責模板、內部代號
- level：1 初階必備 / 2 中階 / 3 高階，抓 60/30/10 比例

## 輸出 B：中文詞 → 英語詞彙（80~120 條）★核心價值
從檔案 3 挑「他工作中天天講、但可能不知道英文怎麼說」的詞，給對應英文＋例句：
{"zh":"備品","en":"spare unit / spare part","example":"We will ship a spare unit first."}
- 略過：n-gram 碎片（如「修完成結」「品交換作」）、公司名（京元/好修/沛頓等）、地名人名
- 一個中文詞可給 1~2 個英文說法（斜線分隔）
- example 要是可直接用在信件/對話的句子
- 優先收：維修流程詞（返修/待驗/結案/借出/親取/上電/量測/子板/特殊板型/追加/報價中…）

## 輸出
寫檔 `kids/tools/_codex_rebuild.json`：{"en_terms":[…],"zh_to_en":[…]}
回覆只要統計摘要。不要動其他檔案，不要讀 adult/ 目錄。

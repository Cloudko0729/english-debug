# 小島金幣回收機制 — Claude 版設計（2026-07-11，未看 Codex 版）

## 問題分析
島蓋滿＋建築升滿星後，金幣只進不出 → 數字無意義 → 答題動機下降。
需要的是「**持續性**的花錢理由」，且花錢本身要好玩，不是懲罰。

## 設計原則
1. Sink 必須 recurring（一次性大建築只能撐幾週）
2. 花錢要有「看得到/摸得到」的回饋（裝飾、寵物、活動、面子）
3. 不花錢不懲罰（寵物餓了會難過但不會死；活動不辦只是沒煙火）
4. 儘量搭現有基礎設施（Supabase 信箱、每日答題、島嶼渲染）

## 提案（依優先序）

### S1 送禮系統（社交 sink，開發成本最低）⭐推薦先做
- 花金幣買「禮物」寄給兄弟（走現有 island_messages 基礎）：食物包 50🪙／裝飾小物 150🪙／神秘箱 300🪙
- 對方開信箱收禮 → 拆禮物動畫 → 獲得物品＋自動回謝卡
- 心理學：花錢買人情，雙向刺激（收到的人也想回禮）

### S2 限時裝飾商店＋圖鑑（收集 sink）
- 每週輪替 3~4 樣純裝飾（雕像/噴泉皮膚/櫻花樹/路燈/季節主題），錯過要等下輪
- 價格階梯 200~2000🪙，不加任何數值——純好看＋圖鑑收集（△已收集 12/40）
- 季節限定（萬聖/聖誕/過年）製造「現在不買就沒了」

### S3 寵物養成（持續小額 sink＋情感黏著）
- 領養 500🪙（狗/貓/企鵝/龍），每天餵食 20🪙 或消耗島上食物
- 成長三階段（幼體→成體→閃亮），連續餵 7 天進化；在島上隨機走動
- 斷餵只是坐下難過臉，補餵就恢復——不懲罰

### S4 共同奇觀（三人合作大 sink）
- 三兄弟共同捐款蓋「跨島奇觀」（燈塔 15000🪙／彩虹橋 30000🪙），Supabase 共享進度條
- 完成後三個島都出現地標＋每人稱號；捐最多的掛名「首席建築師」
- 一季一座，做完換下一座 → recurring

### S5 週末祭典（事件 sink）
- 週末可花 800🪙 辦「島嶼祭典」：煙火動畫＋快樂度 buff 三天＋隨機掉 1 個限定裝飾
- 兄弟可「來訪參加」你辦的祭典（互相拜訪彼此的島＝展示動機）

## 反向設計（不做的）
- ❌ 金幣稅/建築維護費：懲罰感，會討厭系統
- ❌ 賭博式抽獎當主 sink（神秘箱只做保底無重複的溫和版）
- ❌ 玩家間金幣轉帳：會被拿來「哥哥壓榨弟弟」
- ❌ 通膨重置（砍幣值）：毀信任

## 建議節奏
第一波：S1 送禮＋S2 限時商店（一週內可上線）→ 觀察花錢意願 → 第二波 S3 寵物 → 第三波 S4 奇觀（暑假大目標）

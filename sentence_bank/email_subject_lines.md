# Email Subject Lines

讓客戶和原廠一眼看懂主旨的寫法。格式：[狀態/動作] 識別碼 - 說明

---

## 格式原則

- 用方括號標示動作類型：[ETA Update]、[Status Update]、[Action Required]、[Follow-Up]
- 加上識別碼：RMA 編號、型號、料號、SN
- 說明部分簡短具體

---

## 維修 / RMA

- [ETA Update] RMA-24581 - Replacement Board Shipment
- [Status Update] RMA-24581 - Repair Completed, Ready to Ship
- [Action Required] RMA-24581 - Please Confirm Shipping Address
- [Follow-Up] RMA-24581 - Awaiting RMA Authorization Number

## 技術問題

- [Status Update] Model X200 - Test Result Pending
- [Follow-Up] Model X200 - Root Cause Analysis Update
- [Action Required] SN 12345 - Please Provide Log File and Firmware Version
- [Update] SN 12345 - Issue Reproduced, Investigating Root Cause

## 料號 / 規格確認

- [Action Required] PN 88-2041A - Spec Confirmation Needed
- [Confirmed] PN 88-2041A - Part Number and Spec Verified
- [Follow-Up] PN 88-2041A - Replacement Part Compatibility Check

## 交期 / 出貨

- [ETA Update] PO-2026-0601 - Shipment Delayed to June 11
- [Shipped] SN 12345 - Tracking Number Inside
- [Action Required] PO-2026-0601 - Please Confirm Receipt
